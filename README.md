## ✨ Overview

**TovekShop** revamps static server shops with a living, breathing economy model. Every buy and sell transaction impacts market prices according to real supply and demand algorithms, protected by per-item configurable price floors and ceilings to prevent market collapse.

## 🎮 Commands & Permissions

| Command | Permission | Description |
| :--- | :--- | :--- |
| `/shop` | `shop.use` | Opens the main visual category browser |
| `/sell hand` | `shop.use` | Sells matching items currently held in main hand |
| `/sell all` | `shop.use` | Sells all sellable items in inventory with chat summary |
| `/shop reload` | `shop.admin` | Hot-reloads all items, prices, and categories |

## ⚙️ Installation

1. Download `TovekShop-1.0.0.jar` from [Releases](https://github.com/toprakeker/TovekShop-Demo/releases).
2. Place the JAR into your server's `plugins/` directory.
3. Restart or reload via `/tovekshop reload`.
